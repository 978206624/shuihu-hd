# 水浒神兽高清重制 M5.1（性能修复版）

## Windows 启动
1. 先关闭旧版本的 Python/启动黑窗口和旧游戏标签页（避免8765端口仍由旧包占用）。
2. 解压整个 shuihu-hd-m5.1 文件夹，双击 start.bat；需要已安装 Python 3。
3. Chrome 打开 http://127.0.0.1:8765，按 Ctrl+F5 强制刷新一次，确认页头显示“M5.1 · 性能修复版”。
4. 电池存档仍在同一浏览器/同一地址的 localStorage 中；建议先在旧版导出 .sav 备份，必要时在新版导入。

## 修复
- 标题淡出、字幕卡由每行全画布回写改为每帧一次上传。
- 对话边框与认证快照按精确依赖缓存，原生人物、文字继续逐像素保留。
- 扫描线调色只处理实际需要的图集行；只生成实际绘制的候选图层。
- 缺口审计默认关闭对象记录，测试可用 ?audit=1 或 shuihu.setAudit(true) 开启。
- 重复tile解码复用、精简热循环；原先慢渲染时会截断墙钟时间，现保留积欠并逐核心帧追赶。

ROM、WASM模拟核心、素材与人物均未改；没有平滑放大，没有跳过核心帧。
完整29160帧回归：243/243状态和原生framebuffer检查、243组人物文字保留检查通过；高清完整背景28669帧，像素覆盖99.9871715%，与M5完全相同。

这是性能明显改善版，不承诺所有电脑每个显示帧都不卡。Linux headless Chromium实测普通开场渲染平均38.78→8.54ms、森林22.27→8.06ms，12秒段模拟帧率约59.58（目标59.7275）。字幕/特效仍有少量长帧；3分钟录屏含录制开销，整体约58.81模拟帧/秒。尚未在Windows Chrome实机验收。

操作：方向键移动，X/确定(A)，Z/返回(B)，Enter开始，Shift选择，空格暂停。
仅供已有合法原版的本地研究/私用；无外网服务依赖。
